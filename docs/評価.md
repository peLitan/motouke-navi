### 走らせ方

モデルを使うので、利用者のプランの使用量か API の料金がかかります。次の命令はリポジトリの直下で動かします。

```
claude plugin eval plugin --model <固定の値> --scaffold --allow-real-servers \
  --allow-tools mcp__plugin_motouke-navi-guard_masked-files__read_masked mcp__plugin_motouke-navi-guard_masked-files__list_masked mcp__plugin_motouke-navi-guard_masked-files__check_articles \
```

- `--case` を付けないので、E1 と E2 の両方が走ります。片方だけなら `--case e1-trace-masked` のように足します
- `--model`: モデルを固定します(公式「Pin it in CI so a model rollout isn't mistaken for a plugin regression」)。`<固定の値>` は走らせる人が決めます。モデルの入れ替わりを、プラグインの変化と取り違えないためです

- `--no-publish`: 既定では報告が claude.ai へ公開されるので、必ず付けます
- `--ablation with-without`: プラグインなしの回も走らせて差を出します。なしの回は `read_masked` の検査が必ず落ちるので、差にはその1点分が含まれます
