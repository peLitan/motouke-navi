# critic の点検と対応(F08)

点検した日: 2026-11-02。点検の係(critic)は、作った側の説明(進み具合の記録・報告・README・設計の文書・commit の文)と仕込み表を見ずに、次のものだけを見た。

- ツールの出力: `node scripts/run-fixtures.mjs` で、架空の書類 `fixtures/` の3件(A 市道の改良工事・B 共同住宅の新築工事・C 倉庫の造成工事)に、施工体制台帳の点検と施工計画書の目次の点検をかけた結果

critic は書類を自分で読んで見落とし・言い過ぎを探したが、仕込み表は見ていない。下の「見落とし」「言い過ぎ」は critic の読みであって、採点(仕込み表との照合。F04b)の結果ではない。
