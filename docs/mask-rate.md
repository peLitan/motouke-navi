# 置き換えの評価(漏れと置き換えすぎ)

架空の書類(`fixtures/` の3件の工事、各3ファイル)を置き換えの部品で置き換え、「隠すべき語」の正解の表と比べて数えます。

## 正解の表

- 正解の表は、置き換えの部品を作った係とは別の文脈が、このリポジトリの外に作ります。リポジトリには入れません(作った側が正解を作ると、作りに合わせた答えになるため)
- 形は CSV(UTF-8、見出し行あり)の `file,text,kind`。`file` は `fixtures/` からの相対パス、`text` は隠すべき語(書類の中の書き方のまま)、`kind` は 人名・会社名・現場名・住所・電話・メール・許可番号 のどれか

## 数え方

- 漏れの率 = 正解の語のうち、置き換え後の文に元のまま残った数 ÷ 正解の語の数(空白の有無は無視して探す)
- 置き換えすぎの率 = 置き換えた語(書類ごとに重ねずに数える)のうち、正解のどの語とも重ならない数 ÷ 置き換えた語の数
- 一部だけ(参考)= 元のままは残っていないが、1つの記号で丸ごと置き換わってもいない正解の語の数(住所の一部だけが残るなど)
- 2通りを出します。辞書に語を足さない場合と、正解の表の人名・現場名を同じ工事の辞書に足した場合(利用者が自分の現場の名前を足して使う場合にあたる)

## 回し方

```
node scripts/mask-rate.mjs <リポジトリの外の正解の表.csv> [--fixtures fixtures]
```

件数と率だけを出します。表の語は画面にも出しません。正解の表がリポジトリの中にあれば止まります。

## 結果

まだ測っていません(正解の表での採点を待っています)。
