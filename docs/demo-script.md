# 3分の動画の台本

- 長さ: 12場面で合計 2:58(審査の上限の 3:00 以内)
- 話の線: 公告1枚から、要るものを根拠つきで示す1本の話。背景 → 目的 → 手順の順に進める
- 映すもの: このリポジトリで期間中に作った物だけ(今の `index.html` と本物の Claude Code)。下請けの書類は架空の見本。鍵や個人の情報は映さない
- 声は作者本人が読む。字幕は1行13字以内・2行まで(空白は数えない。隅の注記は数えない)
- Claude の動きは毎回違う。端末の場面が台本と違ったときは、撮った回の数と結果に合わせて読み替える(結果を作らない)
- 実在の公告は1件だけ使う(出典は下の「場面の補足」の2)。公告の PDF には担当者の氏名と電話の番号があるので、PDF は映さない。氏名と番号を伏せた文を使い、寄るのは拾った表の2行だけで、ほかはぼかす

## 場面の補足

- 止まった画面を続けない: 4〜6秒ごとに、寄る・押す・流す・札のどれかを入れる。端末の待ちは早送りにし、隅に「早送り」と出す(実際の長さを隠さない)
- 2: 出典は岡山労働局「入札公告 新見労働基準監督署屋上防水及び内壁等改修工事」(令和8年7月14日、https://jsite.mhlw.go.jp/okayama-roudoukyoku/content/contents/002731806.pdf )。公共データ利用規約(第1.0版)(PDL1.0。岡山労働局の利用規約 https://jsite.mhlw.go.jp/okayama-roudoukyoku/link_chosakuken_menseki.html )で利用する。取得日 2026-11-06。作者が文にし、氏名と電話の番号を伏せた。隅に「作者が加工」と出し、岡山労働局が作った画面のように見せない
- 3: 「確かめが要る」の欄の数は字幕に出さない。[docs/評価.md](評価.md) の8の岡山労働局の測りでは15欄のうち1欄で、撮った回の数はこれと違うことがある
- 4: 画面に入るのは発注者、工事の種類、請負代金の見込みの3欄だけ([docs/manual.md](manual.md) の `bid-intake` の節)。この公告は予定価格の額が無いので、入るのは発注者と工事の種類の2欄。請負代金の見込み、元請けか下請けか、下請けの総額、許可の種類は仮の値を手で入れる
- 5: 「判断できない」が出なければ、2文目の後半を「推測では埋めません」と読む
- 6: 工種の欄は条件の工事の種類のページにあり、結果のページでは替えられない。確かめのページの「条件を直す」の「工種を変更」で替え、「次へ」で公告のページまで進んで「確認する」→「この内容で結果を見る」で出し直す。この公告は建築一式なので、替えたあとの建築の結果が公告に合う
- 7: 点検を頼む `prompt` を先に貼ると、Claude が最初から `read_masked` を使い、`Read` が止まる所は映らないことがある。なので先に「raw/施工体制台帳.md を Read で開いて」と打つ
- 8: 貼る `prompt` は `plugin/evals/cases/E1_しおかぜ町下水道/case.json` のもの。作業フォルダには、同じケースの架空の `raw/` だけを写す
- 9: 18件・崩れた 2・確かめられない 1(残る 15)は、[docs/manual.md](manual.md) の「走らせた記録」(2026-11-05、評価のケース E1 の架空の書類2件)の数。撮った回の数が違えば、声と字幕を撮った回の数に替える
- 10 の札1: 手で調べた時間はまだ測っていない。作者が 2026-11-07 に実在の公告2件を手と道具の両方で調べて測り、公告ごとに「手で ○分/道具で ○分」と札に並べる。隅に「2件・1人・各1回」と出し、「何割減」とは書かない。場面の表の字幕と声の1文目は、測った形に合わせて読み替える。2件とも測れなかったら札1 と声の1文目を外し、札2 を 2:08 から始めて5秒延ばす。1件だけ測れたら札1 をその1件の形で出し、隅の「2件」を「1件」に、「各1回」を「1回」に替える
- 10 の札2: [docs/評価.md](評価.md) の7の走らせ直し(古い組(検査9つ)の名前の検査8つで、あり 8/8・なし 0/8)。やりとりの記録(trace)に元の名前が出なかったという意味で、架空の書類の8つの名前だけを調べた数
- 10 の札3: [docs/評価.md](評価.md) の8の「公開の公告2件」の P1 岡山労働局(正しく拾えた 11・正しく「書いていない」 3・漏れ 1)。1件・1回なので率ではない
- 12: GitHub の URL は提出の前に作者が入れる
